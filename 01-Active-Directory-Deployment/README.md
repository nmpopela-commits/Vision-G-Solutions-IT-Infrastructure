# Project 01: Active Directory Infrastructure Deployment

## 1. Project Overview

This project documents the deployment of a Windows Server-based Active Directory environment for Vision G Solutions, a simulated business consulting organisation.

The infrastructure will provide centralised identity management, domain authentication, DNS services and a foundation for future enterprise IT administration and troubleshooting projects.

## 2. Business Requirements

Vision G Solutions requires an internal IT environment that supports:

- Centralised employee authentication
- Management of domain-joined workstations
- Organisational separation of departments
- DNS-based resource discovery
- Centralised security and configuration policies
- Future integration with file services and infrastructure monitoring

## 3. Planned Infrastructure

| Component | Configuration |
|---|---|
| Virtualisation | Oracle VirtualBox |
| Server operating system | Windows Server 2022 |
| Domain controller | VGS-DC01 |
| Active Directory domain | corp.visiong.co.za |
| NetBIOS domain | VISIONG |
| Workstation | Windows 10 |
| Domain services | Active Directory Domain Services, DNS |
| Networking | Isolated virtual lab network |

## 4. Implementation Phases

- [ ] Prepare Windows Server 2022
- [ ] Configure server hostname and IP addressing
- [ ] Install Active Directory Domain Services
- [ ] Deploy the new Active Directory forest
- [ ] Configure and verify DNS
- [ ] Join Windows 10 to the domain
- [ ] Validate domain authentication and connectivity
