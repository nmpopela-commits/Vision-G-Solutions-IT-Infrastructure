# Vision G Solutions | Enterprise IT Infrastructure Lab

**Windows Server 2022 | Active Directory | Networking | IT Support | Infrastructure Monitoring**

## Project Overview

Vision G Solutions is a fictional South African business consulting and outsourced services company created to simulate a real-world corporate IT environment.

This homelab project focuses on designing, deploying, administering, and troubleshooting Windows-based enterprise infrastructure.

The goal is to develop and demonstrate practical skills in systems administration, networking, end-user support, infrastructure security, and technical problem-solving.

## Business Environment

**Organisation:** Vision G Solutions (Pty) Ltd  
**Location:** Pretoria, South Africa  
**Industry:** Business Consulting and Outsourced Services  
**Employees:** 12  
**Departments:** Executive, Finance, Human Resources, Operations, Sales & Marketing, and IT

## Lab Infrastructure

The environment uses VirtualBox virtual machines to simulate the company's internal network.

| System | Technology | Purpose |
|---|---|---|
| Domain Controller | Windows Server 2022 | Active Directory, DNS and Group Policy |
| Workstation | Windows 10 | Domain authentication and end-user support |
| Monitoring Server | Ubuntu / Splunk | Centralised log collection and monitoring |
| Diagnostic Workstation | Kali Linux | Network testing and troubleshooting |

**Planned Active Directory domain:** `corp.visiong.co.za`
